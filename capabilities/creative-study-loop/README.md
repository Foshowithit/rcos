# Creative study loop (reference -> measured targets)

Registry id: `creative-study-loop` · kind: `runbook`

The acquisition loop that turns best-in-class creative work into measured
targets our productions are gated against. Home:
`~/.zcode/workspace/default/creative-study/`.

## The loop

1. **Queue** (`QUEUE.md`): a unit = one class × a small corpus (3–6 works),
   chosen because it maps to live work (bearing-film, fapcoin, Too Hot,
   explainer) or a named gap.
2. **Measure** (`rig/run_on_dell.sh fetch/local`): every source becomes a
   forensics receipt (see `video-forensics-receipt`). Our own films go through
   the same rig, so comparisons are apples-to-apples.
3. **Read** the contact sheets + numbers; separate what the canon does from
   what a single film happens to do.
4. **Publish targets** (`PLAYBOOK.md`): envelope rows per class with the study
   slugs they came from, a column for our current film, and the measured gap.
   No citation, no target.
5. **Gate**: production reviews check the playbook rows for the class; the
   target's acceptance is a number, not an adjective.
6. **Log**: each round is an RCOS eval on this capability + the rig's.

Rules: third-party media never enters a repo (derived measurements only);
studies serve live work or named gaps; a claim lives in the playbook only with
a receipt behind it.
